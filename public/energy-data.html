원천데이터 운영 원칙

공식 API 우선

뉴스 기사나 비공식 웹시세에서 숫자를 추출하지 않고 KPX·EIA 공식 응답만 저장합니다.

원천·요약 분리

시간별·관측별 원천 레코드를 연도 파일에 보존하고 일별 요약은 원천파일에서 매번 재계산합니다.

수정값 덮어쓰기

같은 날짜·시간·지표가 재공개되면 최신 공식값으로 교체하며 중복 레코드는 만들지 않습니다.

시차 명시

EIA 값은 한국 기준일과 공개 시차가 있으므로 각 수치 옆에 실제 관측일을 별도로 표시합니다.
