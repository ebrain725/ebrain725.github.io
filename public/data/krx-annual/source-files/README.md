# KRX 업체현황(연간) 원자료 개별파일

업로드된 `Policy.zip`의 내용을 항목·연도별 CSV 60개로 풀어 GitHub Pages 공개 폴더에 제공합니다.

- [원자료 개별파일 목록](https://ebrain725.github.io/data/krx-annual/source-files/)
- [원본 ZIP 다운로드](https://raw.githubusercontent.com/ebrain725/ebrain725.github.io/main/source-data/krx-annual/Policy.zip)
- [원본 ZIP 저장 위치](https://github.com/ebrain725/ebrain725.github.io/blob/main/source-data/krx-annual/Policy.zip)
- [추출 스크립트](https://github.com/ebrain725/ebrain725.github.io/blob/main/scripts/extract_krx_annual_sources.py)

공개 목록은 총수량, 사전할당, 추가할당, 할당취소, 인증배출량, 이월량, 차입량, 상쇄배출권 발행량으로 구분합니다. 원본 ZIP은 수정하지 않으며, GitHub Pages 배포 시 `public/data/krx-annual/source-files/` 경로에 개별파일과 `manifest.json`, `index.html`을 생성합니다.
