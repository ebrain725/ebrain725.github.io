## 검증

모든 월에 대해 다음 항목이 일치하는지 확인했습니다.

1. 전체 매도량 = 전체 매수량
2. 73개 업종 합계 = 할당대상업체 소계
3. 할당대상업체 소계 + 할당업체외 소계 = 전체 합계

화면의 순매수량은 `매수량 − 매도량`으로 계산합니다.
